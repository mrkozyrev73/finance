# Мои доходы

Приватное семейное PWA для учёта ожидаемых и полученных доходов, статистики и финансовых заметок.

## Безопасность

- исходный репозиторий должен оставаться **private**;
- финансовые данные не хранятся в GitHub;
- доступ к данным идёт через Supabase Auth;
- таблицы Supabase закрыты Row Level Security и доступны только участникам одного семейного пространства;
- в браузер передаётся только публичный `publishable key`; `service_role` в приложение добавлять нельзя.

## Запуск

Приложение статическое: для разработки достаточно открыть `index.html`. Для установки на iPhone нужен HTTPS-хостинг, затем в Safari выбрать «Поделиться» → «На экран Домой».

## Supabase

1. Создать приватный проект Supabase.
2. Выполнить целиком файл `supabase-schema.sql` в SQL Editor.
3. В настройках приложения указать Project URL и Publishable key.
4. На первом телефоне войти по email и создать семейное пространство.
5. На втором телефоне войти по другому email и присоединиться по коду.
